# 界面多语言（i18n）

插件给人看的文字跟随 DSH 的界面语言，覆盖 DSH 提供的全部 8 种：`zh`、`en`，以及 DSH 通过 `locale.addLanguage` 加入的 `ja`、`es`、`fr`、`de`、`ru`、`pt`，后六种都回退到 `en`（`dsh-client-locale/lib/client.js`）。给模型看的文字（提示词、工具描述、调度器报错）一律保持英文，不翻译。

## 结构

| 文件 | 作用 |
|---|---|
| `src/i18n/zh.ts` | 键集合的唯一来源 |
| `src/i18n/{en,ja,es,fr,de,ru,pt}.ts` | 每个文件的类型都是 `Record<keyof typeof zh, string>`：漏键或多键会在编译时报错 |
| `src/i18n/index.ts` | `DICTIONARIES`、`LANGS`、`langOf`、`pluralForm`、`t` / `tn` |
| `locale/<lang>.json` | 插件页上的 `meta.title` / `meta.description`，由 dsh-app-boot 的 `readPluginMeta` 读取 |

- **浏览器端**：`register('agentScheduler', DICTIONARIES)` 一次注册 8 种语言。DSH 的 `register` 接受任意符合 BCP 47 形式的语言 id。
- **宿主端**（斜杠命令的回复）：读 Host 设置里的 `locale.preference`。`langOf` 取语言 id 的主子标签，例如 `pt-BR` → `pt`；不认识的语言回落到 `en`；从没选过语言时仍为 `zh`，和以前一样。

## 复数

DSH 自己的词典也只用 `.one` / `.other` 两种形式（例如 `dsh-client-ui-subagent` 的 `count.running.*`），插件沿用同一方案：

- `tn()` 用 `Intl.PluralRules(<当前语言>)` 判断：结果是 `one` 就用 `.one`，否则用 `.other`。所以 fr / pt 的 0 用单数，ru 的 21、31… 也用单数（`21 агент`）。
- **ja / zh**：没有单复数之分，`.one` 和 `.other` 写成同一句（有测试保证）。
- **ru**：`few`（2–4）和 `many`（5 以上）都落到 `.other`。因此每个 `.other` 写成对任何数字都通顺的「名词: {count}」句式，例如 `Агентов: {count}`、`Ждут вас: {count}`，不写成某一种变格。
